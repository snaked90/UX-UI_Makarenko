# lab-02 — Персони користувачів Assay

Практична робота №2 з дисципліни «UI/UX дизайн».
Тема: розробка персонажів користувачів (User Personas) та карти емпатії.

Продукт — **Assay**, легкий десктопний застосунок для тестування API (див. [`lab-01`](../lab-01)).
Цільова аудиторія: студенти-розробники та тестувальники, яким потрібен простий інструмент для разових перевірок API.
