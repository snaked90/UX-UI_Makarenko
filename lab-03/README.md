# lab-03 — Проєктування структури взаємодії (Assay)

Практична робота №3 з дисципліни «UI/UX дизайн». Продукт: **Assay** — легкий десктопний застосунок для тестування API.

## Артефакти

У Figma схеми розташовані на **трьох фреймах**:

| Фрейм у Figma | Що на ньому | Рисунки у звіті |
|---|---|---|
| Sitemap | Карта екранів: Splash - Робочий простір - Запит, Колекції, Історія, Налаштування (+ Про застосунок) | Рис. 1 |
| Flows | Усі три Task Flow на одному фреймі: перший запит, повторення збереженого запиту, обробка помилки | Рис. 2–4 (у звіті розділені для зручності) |
| States | Empty State та Error State | Рис. 5 |
